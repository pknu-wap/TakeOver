# 시스템

## 게임 루프

**확정 — 캘린더(하루 단위) + 행동포인트(AP) 예산제.**

- 하루마다 행동포인트가 있고(예시 총 50, 확정 아님) 선택할 때마다 소모된다(예: 지분 매입 10 · 협상 이벤트 15, 실제 값 미정)
- 조건을 만족한 이벤트가 화면에 후보로 뜨고, 유저가 클릭해서 선택·실행
- **하루 마감은 유저가 버튼을 직접 눌러야 넘어간다** — AP가 남아도 자동으로 다음 날로 안 넘어감
- UI (미확정) : 메인 화면에 이벤트를 시각적으로 배치, 클릭 시 개요 설명 + 소모 AP 표시
- 미해결: AP 총량 · 이벤트별 소모량 수치

## 투자 시스템 (INVEST)

**확정된 것**

- 플레이어는 자기 사업장이 없다 — **지표를 읽고 지분을 사는 것이 행동의 전부**
- 지표: 매출 · 부채 · 영업이익
- 지분율이 오르면 경영 방향에 개입할 권한이 **단계적으로** 열린다
- "인수한 기업 관리" = 이 개입 선택지 그대로. 별도 운영 화면 아님
- 기업 브라우징 방식 — 리스트와 맵 구조.
    - 리스트는 접근 가능한(모든 기업을 보여줄 지는 미정) 기업의 정보를 보여줌. (모든 기업을 보여준다면 UI적으로 강조 우선순위를 나눌것)
    - 맵은 기업간 상호작용, 관계를 표시. 게임 후반에는 기업, NPC와의 상호작용을 하는 데 초점을 둠. (명확히 기획되지 않음)
- 매입 흐름 UI — 얼마나 살지 결정하는 화면, 자금 관리
    - 매입

        매입은 행동을 소모하지 않으며 일 1회만 두는건?
        
- 지분율 단계가 몇 단계로 나뉘는지, 각 단계에서 정확히 뭘 할 수 있는지
    - 지분 (최대주주 내용 기획 명확히 정해지지 않음)
        - 분류는 0~10%, 11~24%, 25%~50%, 51%+
        
        0~10%

        - 0이랑 동일
        - 지분 매매
        - 기본 공개 정보 확인
        - 가치 상승에 따른 수익

        - 제한적인 NPC 접촉

        - 다음 행동 의도 일부 예측
        - 회사에 전략적 제안 가능
            - 사업 / 전략 / 자금지원 / 인력지원 / 협력요청 등등…
        - 비공개 지표 대부분 공개 (관측도 보너스)

## 이벤트·협상 시스템 (ACQUISITION)

**확정된 것**

- 미니게임이 아니라 **순수 대화 분기**로 간다 — 확률 없이 항상 성공하고 **대가만 갈린다**
- 대가는 평판이 기본이되, 이벤트에 따라 다른 축(자금 등)도 트레이드오프로 걸릴 수 있다. 선택지 개수는 이벤트마다 다름
- 이벤트 종류(예시, 계속 늘어남): 주가조작 권유 · 정치 결탁 · 언론 매수 · 정보 유출 · 담합 · 구조조정
- **메인 이벤트**(스토리 필수, 무조건 발생 — 예: 최종 보스 중반 역공)와 **그 외 이벤트**(조건부 발생)로 구분
- 발생 메커니즘은 두 갈래: ①직접 연계(이전 선택의 수락/거절을 저장해 특정 후속 이벤트를 열기) ②조건 게이팅(평판 수치 조건으로 발생 여부 결정(개별 NPC의 특정 변수의 값 ex : Hostility). 별도의 "기억 태그" 레이어는 없음
- 트리거 재료(지분율·평판·진행도·NPC 관계·랜덤)는 이벤트별로 개별 설계, 복수 재료 동시 조건도 가능
- 최종 보스 역공: 유저 총 자본(지분+인수 회사 가치 합)이 임계값을 넘으면 그 시점부터 게임이 끝날 때까지 지속적으로 발생하는 이벤트들이 시작된다(1회성 이벤트 아님, 트리거 수치 미정)
- 조건 충족 이벤트는 자동 실행이 아니라 화면에 후보로 뜨고 유저가 클릭해서 선택
- 연계가 1:1인지 다단계 사슬까지 가는지, 평판 게이팅의 방향·축 결합 방식 — 이벤트에 따라 상이
    - 각 이벤트별 구체적인 트리거 세부 조건,수치, 최종 보스 인지 임계값은 미정

**예시 — 주가조작 이벤트**

와이어프레임+흘름도: https://claude.ai/code/artifact/5cecd38d-2d55-4a36-a500-6993a7a9f020

- 발생 주체: **M&A브로커 윤하진**(외부 NPC)이 접근해 제안 (플레이어가 먼저 거는 게 아님)
- 트리거: 대상 회사의 소비자 반응이 낮음 AND 경제지기자 이민규 · 탐사보도기자 정수아와의 관계가 우호적(구체 조건 미정, 예: Hostility 낮음)
- 수락 시: 윤하진과의 관계 Trust▲·Dependency▲ / 대상 회사 소비자 반응 하락(Publicity 높은 사건으로 기록) / 정수아와의 관계 Hostility▲·Interest▲(변화폭 미정) — 직원▲·투자자▼·경쟁기업▼는 폐기된 축이라 삭제
- 수락 시 금전 이득: 다음 날 보유 종목 중 하나가 랜덤으로 골라져 30~40% 급상승(pump) → 플레이어가 원하는 타이밍에 수동으로 팔아야 차익 실현(안 팔면 나중에 다시 꺼질 리스크)
- 거절 시: 조용히 거절한 사건이라 Publicity 없음 — NPC 관계·소비자 반응 전부 불변
- 연계(언론 조사): 트리거는 "수락"이 아니라 "급상승한 시점에 실제로 매도함" — 매도한 뒤로 하루 마감마다 조사 착수 여부가 갈린다. 확률은 **정수아와의 관계(Interest 등)에 연동될 예정**(정확한 수식 미정). 이 이벤트도 순수 대화 분기(확률 없음)로 돈으로 막는다(대가=자금, 수치 미정) / 그냥 둔다(→ 보유 포트폴리오 전 종목 주가 하락, 하락폭 미정) 중 선택

**⬜ 아직 미정**: NPC 관계 변화폭 수치, 소비자 반응 트리거 임계치, 조사 확률-Interest 연동 수식

## NPC·기업 구조 시스템 (NPC_STRUCTURE)

**원본 문서**

TakeOver_NPC_기업구조_기획서_v3.pdf

**개요 — NPC는 대화 상대가 아니라 시장을 움직이는 행위자다**

- 플레이어의 인수·협상·구조조정·언론정치개입·지분매입의 결과가 NPC의 기억(Memory)으로 남고, 다음 협상의 조건·선택지를 바꾼다
- NPC 구성 요소: Identity(직책·성격·목표·민감가치) / Dynamic State(현재 관계·상황) / Memory(과거 사건) / Preference(선호·기피 행동) / Decision Model(회사상황+개인성향+기억 종합) / Relation Network(NPC끼리도 관계로 연결)

**관계 변수 6개** : Trust · Respect · Fear · Hostility · Dependency · Interest (보조: Pride/Integrity/Ambition, NPC별 가중치 다름)

**이벤트 변수로서의 합산** — 상시 추적되는 "평판" 축은 없지만, 특정 이벤트 설계 시 관련 NPC 여러 명(예: 언론 카테고리의 이민규+정수아)의 관계 수치를 그 이벤트 하나에만 쓰이는 합산값으로 계산해 트리거·대가에 쓸 수 있다. 상시 존재하는 독립 수치가 아니라, 그 이벤트 하나만을 위해 그때그때 계산하는 일회성 계산식이다(합산/평균/가중치 등 계산 방식은 이벤트마다 개별 결정).

**Memory 시스템**

- 모든 행동을 기록하지 않는다 — ①관계에 의미 있는 행동(약속 이행/파기, 개인적 도움) ②기업 상태를 바꾸는 행동(지분 확보, 인수합병, 구조조정, 인력 영입/해고) ③업계·평판에 영향 주는 행동(정보유출, 언론개입, 정치거래, 담합, 불법거래, 공개적 경쟁사 공격) 중 하나 이상일 때만 생성
- 필드: MemoryID(사건 태그) / ActorID / TargetID / Strength(충격도 1~5) / Turn / Publicity(PRIVATE~PUBLIC 공개범위) / Permanent(장기 지속 여부) / Reliability(증거 확실성) / Interpretation(NPC별 다른 해석) / Tags
- 같은 행동도 NPC마다 다르게 해석·기억됨 (예: 구조조정 → CFO는 COST_RESTRUCTURING/Respect↑, 현장책임자는 MASS_LAYOFF/Hostility↑)
- 기억은 시간이 지나면 영향력이 약해지지만 삭제되지 않는다(Permanent=true는 거의 감소 안 함); 같은 유형 반복 시 "누적 강도"로 성향 태그(PLAYER_STYLE_HOSTILE 등) 생성 → 새 NPC의 첫인상에 반영

**21. APEX Corporation = 최종 보스** (종합 기업집단, 시장 지배와 통제). 5명: 회장겸CEO 강태문 · CFO 이서현 · 그룹전략총괄 정우진 · 대외관계총괄 차유라 · 법무책임자 강현식. 최종전은 주가로 이기는 싸움이 아니라 "플레이어가 지금까지 무엇을 기억시켰는지"로 갈리는 구조

**외부 NPC 8명** (특정 기업 소속이 아니라 사건·거래망을 옮겨다님): M&A브로커 윤하진 · 경제지기자 이민규 · 탐사보도기자 정수아 · 기관투자자 김태성 · ESG투자담당자 문채원 · 정치로비스트 박상현 · 노동계대표 유재호 · 기업법무전문가 정예린

**NPC 행동 의사결정 모델**: 개인목표 + 기업상황 + 플레이어 관계(Trust/Respect/Fear/Hostility) + 기억 + 조직반응(다른 핵심NPC 태도) + 외부압력(언론/정부/투자자/노동계) 종합

**파생 지표 — 소비자 반응**

특정 NPC 한 명이 대표하지 못하는 대중 반응이라 따로 계산한다. NPC Memory 중 **Publicity(공개도)가 높은 사건만** 반영하고, 비공개로 남는 사건은 영향 없다. 이 값은 화면에 별도 게이지로 안 보여주고, 해당 회사의 매출·성장률에 반영되어 주가·기업가치 변화로만 드러난다(플레이어가 보유한 지분 가치에 실시간 반영).

**유저에게 보여줄 수치 — 두 묶음만**

- 회사 재무 지표(매출·부채·영업이익·주가/지분가치) — 객관적 숫자, 항상 화면에 노출
    - NPC 관계 — 사람 단위, 숫자 게이지 대신 정성적 신호(관계 단계 라벨·표정·대사 반응)로 표현한다.

**엔딩 분기 재료** (평판은 아니지만 같은 맥락)

- 플레이어 성향 태그(PLAYER_STYLE_HOSTILE 등) — 전역 누적, 특정 회사 아니라 플레이어 전체 단위
- APEX(최종보스) 개별 NPC와의 관계 — 최종전 결과에 직접 반영
- 포트폴리오 규모(총 지분 가치 등 순수 재무 수치)

**⬜ 아직 안 맞춰본 것**

- 각 NPC의 수치 가중치, 고유 협상 조건, 배신·제보·이탈 조건은 "체크리스트"로만 남겨뒨 — 실제 테이블화는 다음 단계
- 소비자 반응 Publicity 임계치, Memory 태그별 변화폭 수치
- NPC 관계를 화면에 어떤 정성적 신호로 보여줄지 구체 방식
