# 캐릭터 설정에 따른 Memory 호불호 보너스 — 2026-11-08

현재 NPC SO의 성격·가치관·역할과 실제 이벤트가 발행하는 Memory를 근거로 조정한 1차 밸런스다. 이벤트 선택지·대사·기본 효과·비용·발생 조건은 유지했다.

## 현재 적용 정책

- 등록 NPC 14명과 신규 양식의 **보너스 기준 = 기억 (Memory)만**이다. 기존 행동별 분류는 보관하지만 보너스 계산에는 사용하지 않는다.
- NPC 공통 배율은 끄고, 54개 Memory 항목에 각각 개별 배율·관계 축·설정 근거를 넣었다.
- 고정 추가 변화량은 모두 0이다. 실제로 받은 Memory의 기존 변화량 중 호불호 방향과 선택 관계 축에 해당하는 부분만 **1.10~1.40배**로 증폭한다. 기존 인물별 사건 보정은 유지한다.
- 두려움·의존도는 이번 보너스에서 제외한다. 조사·사업 관심도는 캐릭터별로 구분한다.
- 표에 없는 유형과 **Custom은 보너스 중립**이다. 해당 Memory를 실제로 받았을 때만 설정이 적용된다.

괄호 안은 배율 적용 관계 축이다. 선호는 유리한 방향, 불호는 불리한 방향의 기존 변화만 증폭한다. 기존 변화의 부호를 뒤집지 않는다.

## 일관성 판단의 핵심

- **강준혁**: 계약·회사 정체성·현장 연속성을 중심으로 약속 이행을 신뢰하고 계약 위반·감축·적대적 인수에 반발한다.
- **서지아**: 확인 가능한 약속과 재무 합의 위반을 구분한다. 현재 내부정보 이벤트의 문서화된 성과보수 거래가 `LeakedInfo`로 기록되므로 그 긍정적 신뢰·관심 변화만 1.20배 적용한다. 해고 자체는 재무 성과의 근거가 부족해 중립으로 둔다.
- **박도식·최미정·박민우**: 현장·직원 권리 보호와 조직 중재의 차이를 반영했다. 박도식·최미정의 대규모 감축 반발은 1.40배, 박민우는 1.25배다. 단계적 전환은 현재 `Custom`이므로 기본 신뢰 변화만 유지한다.
- **김하린**: 브랜드 신뢰·소비자 약속·장기 존속에 무게를 두었다. 출처나 정황을 특정할 수 없는 모든 내부정보를 일괄 불호로 넣지 않았다.
- **오재성**: 원가·생산성·회수 계획을 판단하므로 대규모 감축을 무조건 선호하지 않는다. 고용 유지 선택의 기존 존중 하락도 유지한다. 합의 위반과 법적 위험의 불리한 변화에 반응을 강화한다.
- **강재현**: 성장·실행 성과를 중시한다. 적대적 인수는 기존 이벤트에서 존중과 경계가 함께 오를 수 있어, 보수적 CEO와 같은 일괄 불호를 넣지 않았다.
- **조민석**: 제조업 명예·자율성과 장기 생산 기반을 중심으로 존중·적대감 축에 차이를 둔다.
- **윤하진**: 거래 신뢰와 후속 중개 기회에 초점을 둔다. 주가조작 수락의 `Custom`에는 추가 보너스를 얹지 않는다.
- **정수아**: 뇌물·문제성 정보 유출의 신뢰 하락·적대감을 강화하되, 조사 관심 증가는 기존 값 그대로 둔다.
- **김태성**: 장기 위험·예측 가능한 합의·기업 생존을 우선한다. 인수·해고라는 유형만으로 수익성과 위험을 단정하는 보너스는 넣지 않았다.
- **박상현**: 정치 거래의 실익에 따른 기존 신뢰·의존도는 유지한다. 뇌물 Memory에서 위험을 반영해 생긴 적대감 증가·관심 하락만 1.15배로 강화한다.
- **이민규**: 투명한 수치 공개로 생기는 신뢰·존중을 1.30배로 강화한다. 설명 회피의 `Custom`은 범용 유형이어서 기존 신뢰 하락만 유지한다.

## 현재 이벤트의 변화 예시

| 결과 Memory | 변경 후 관계 변화량 |
|---|---|
| 박도식 대규모 감축 | 적대감 +20 → +28 |
| 최미정 대규모 감축 | 적대감 +20 → +28 |
| 박민우 대규모 감축 | 적대감 +10 → +12.5 |
| 오재성 대규모 감축 | 기존 존중 +10 유지 |
| 오재성 감축하지 않음 | 기존 존중 -10 유지 |
| 이민규 솔직한 수치 공개 | 신뢰·존중 각각 +10 → +13 |
| 서지아 문서화된 성과보수 약속 | 신뢰·관심 각각 +10 → +12 |

`Custom`에는 단계적 감축, 말뿐인 약속, 공개 기부, 그린메일 수락, 주가조작 수락처럼 서로 다른 맥락이 섞여 있다. 이를 한 종류의 선호/불호로 묶으면 캐릭터 설정과 어긋날 수 있어 이번 보너스에서 제외했다. 해당 결과의 기존 관계 변화량은 계속 적용된다.

이번 조정은 과거에 기록된 기억을 다시 계산하지 않는다. 플레이를 다시 시작해 SO를 로드한 뒤 새로 받은 Memory부터 적용한다. 편집 방법은 [NPC_SO_EDITING_KO.md](NPC_SO_EDITING_KO.md)를 따른다.
