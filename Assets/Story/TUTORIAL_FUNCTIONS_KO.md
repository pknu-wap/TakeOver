# 기능 튜토리얼 — 2026-11-10

MainMenu의 새 게임에서 프롤로그와 첫날 체험을 마친 뒤 둘째 날까지 이어진다. 경영 참여·구조조정 실습은 추가하지 않는다. 첫 매수는 1주, 추가 매수는 1주, 첫 매도는 1주이며, 기존 거래·이벤트·NPC·턴 서비스를 사용한다. 거래 결과를 임의 보상이나 가짜 수치로 대신하지 않는다.

## 공용 대화 UI와 이벤트 시연

튜토리얼 대사는 Game 씬의 기존 `EventNegotiationView` UI 인스턴스를 복제해 공용 렌더러로 사용한다. 별도로 만든 튜토리얼 대사 패널·선택지·장 제목 띠는 사용하지 않는다. 이벤트 프리팹의 폰트·말풍선 배경·선택지·인물 프레임을 공유하며, 공용 본문 폭을 넓혀 잦은 줄바꿈을 줄인다. 현재 대사는 한 페이지에서 읽히도록 정리하고 페이지 분할은 아주 긴 대사의 잘림 방지용으로만 둔다.

독백은 이름과 이름 아래 줄·인물 이미지를 숨기고 전체 본문 폭의 중앙에 표시한다. 이야기 속 독백(`Narration`)과 시스템 안내(`System`)를 구분한다. 인물들은 시간·약속·돈·상대의 태도에 대해 구어체로 말하며, AP·버튼·이벤트 조건 등 정확한 기능 설명은 해당 기능 사용 시점의 별도 설명창으로 전달한다. 시스템 안내와 거래 완료 문장은 ‘~하였습니다/~입니다’ 문체를 사용한다.

카드 읽기·기한·AP·만나기·답변·응답·닫기에 대한 설명은 모두 실제 이벤트를 열기 전 설명창에서 끝낸다. 이벤트 카드 탐색부터 실제 상세창과 협상·응답·닫기까지 튜토리얼 안내띠·확인 버튼·강조 테두리·입력 마스크·별도 스킵을 표시하지 않는다. 이때 튜토리얼 Canvas의 GraphicRaycaster도 비활성화한다. 상세창의 돌아가기를 누르면 그대로 닫히며 자동으로 다시 열지 않는다. 카드에서 다시 열어 이어갈 수 있다. 실제 이벤트는 기존 스킵 버튼 하나만 사용한다.


설명창은 기존 이벤트 DialogueBand/QuestionBlock을 복제하고, 스킵·확인·인물 정보 버튼도 기존 닫기 버튼을 복제한다. 배경·서체·밑줄·버튼 프레임은 원본에서 가져오며 배치와 표시 요소만 상황에 맞게 조정한다. 원본 프리팹과 씬 설정은 변경하지 않는다. 버튼은 ‘확인’·‘스킵’으로 표기한다. 별도 제작 요청이 없는 후속 UI도 같은 원칙을 따른다.

인물 정보/기억 설명창은 왼쪽, 대상 정보 화면은 오른쪽에 표시한다. 기업 정보도 설명창과 겹치지 않게 이동한 뒤 단계 종료 시 원래 배치로 돌린다. 주인공 대사는 오른쪽 끝을 이름 밑줄 끝에 맞춘다. 독백은 기존처럼 이름/밑줄 없이 전체 폭 중앙정렬한다. 시스템 안내/거래 결과는 대화 말풍선 대신 공용 설명창에 표시한다. 주가·자금·기업 금액은 정수로, 지분율·부채비율 등 백분율은 필요한 소수점으로 표시한다.

재무 확인 장면은 동행 중인 윤하진이 이어간다. 이 구간에 CFO가 갑자기 등장하지 않는다. 기존 첫날 서지아 소개 및 둘째 날 실제 서지아 이벤트는 유지한다.

## 이야기와 필수 체험

1. 첫날: 도시맵의 미래건설 선택 → 1주 매수 → 강준혁 인물 정보 → 박도식 대화의 관계·기억 확인 → 하루 종료.
2. 둘째 날에 다시 들어온 서지아의 연락: 카드를 열기 전 공용 설명창으로 자세히 보기·요청·기한 확인 방법과, 카드 읽기에 AP가 소비되지 않음을 안내한다. 윤하진은 다음 일정을 짧게 제안한다.
3. 이벤트를 열기 전 일정 설명창: 실제 현재/최대 AP와 만남 비용, 시작 시 소비·답변 시 추가 소비 없음, 부족하면 시작 불가, 하루 종료 시 최대치 회복을 설명한다. 제안의 조건·기한과 선택지 설명을 읽고 판단하도록 안내한 뒤, 실제 카드를 열게 한다.
4. 기존 이벤트 상세창의 만남 버튼 → 플레이어가 세 답변 중 직접 선택 → NPC 응답 → 대화 닫기까지 실제로 진행한다. 모든 답변을 허용한다. 도입부 선택과 같은 가짜 이벤트를 별도 발행하지 않는다.
5. 만남 직전/직후 AP·자금·관계 6축의 실제 값을 비교해 보여준다. 서지아의 인물 정보에서 이번 기억을 확인한다. 신뢰·존중·관심·두려움·적대감·의존도의 의미, 인물별 선호, 비영구 기억의 영향 감소·만료, 만료되어도 과거 관계 변화가 되돌아가지 않음을 설명한다. 관계나 기억만으로 협조가 보장된다고 안내하지 않는다.
6. 미래건설의 매출·순이익·현금·부채비율을 확인한다. 회사 현금과 플레이어 잔액을 구분하고, 기존 주식 매수 대금은 회사 운영자금에 바로 들어가지 않음을 설명한다. 하늘식품의 소개·업종·같은 지표도 필수로 확인한다.
7. 미래건설의 전체 주식 대비 보유량과 지분율을 확인한다. 일부 이벤트의 지분 조건, 날짜 진행 시 조건 판정, 기한과 추가 조건, 매도 등으로 조건을 잃으면 목록에서 빠질 수 있음을 설명한다. 주가가 낮거나 보유 주식 수가 많다고 유리한 투자·경영권 취득을 보장하지 않는다.
8. 남길 현금을 생각한 뒤 미래건설 1주를 **추가 매수**한다. 실시간 입력 수량·예상 대금·거래 후 잔액·보유량·지분을 보여준다. 성공 후 실제 잔액·보유량 전후를 표시한다.
9. 다른 거래의 현금을 확보한다는 흐름에서 미래건설 1주를 **첫 매도**한다. 같은 수량칸과 매도 버튼 사용, 현재 주가 기준 예상 매도 대금, 잔액 증가·지분 감소, 매수 가격과 달라질 수 있으므로 수익을 보장하지 않음을 설명한다. 실제 거래 후 잔액·보유량·지분을 다시 확인한다.
10. 남은 AP와 자금을 확인하고 다음 만남·거래·하루 종료를 스스로 정하는 장면으로 자유 진행에 복귀한다.

## 진행과 스킵

- 총 136개 진행 항목: 중복 규칙 설명 10개를 설명창에 통합하고 현장 대화 요약 1개를 추가했다. 기존 대화 선택 3개/9결과와 별개로 실제 일반 이벤트 선택 1회를 체험한다.
- 필수 목표 14개: 회사 선택, 첫 매수, 대표 정보, 현장 기억, 하루 종료, 이벤트 카드, 실제 이벤트 완료, 이벤트 기억, 미래건설 재무, 하늘식품 비교, 매수 전 지분, 추가 매수, 첫 매도, 매도 후 지분.
- 인물·기업 정보 확인 단계는 대상 화면이 열린 뒤 확인 버튼을 눌러야 진행한다. 거래 단계는 실제 보유량·현금 변화를 확인한다. 실제 이벤트에는 별도 확인 버튼을 붙이지 않고 기존 상세창·선택·결과 닫기를 관찰해 진행한다. 취소·잘못된 수량·실패는 완료로 처리하지 않는다.
- 튜토리얼 중 거래 수량은 단계마다 1주로 제한해 첫 매수에서 자금을 모두 소진하거나 첫 매도 실습 전에 주식을 모두 잃지 않게 한다. 반대 거래·다른 회사 거래·연속 거래·임의 턴 진행은 차단한다. 자유 진행에서 제한을 해제한다.
- 대화창의 스킵은 다음 미응답 선택지 **또는 필수 조작·확인 목표**에서 멈춘다. 필수 목표를 생략하거나 이벤트 답을 자동 선택하지 않는다. 일반 이벤트 내부 스킵은 기존과 같이 응답 연출을 생략할 수 있으나 답변은 직접 고른다.
- 타이틀에서 명시적으로 선택하는 전체 튜토리얼 스킵은 유지한다. 첫 매수·하루 종료·일반 이벤트 기본 첫 답변·추가 매수·매도를 공용 경로로 각각 한 번 처리하고 완료 상태로 진입한다. 최종 미래건설 보유량은 기본 1주, 날짜는 둘째 날이며 일반 이벤트의 실제 AP 비용이 반영된다.
