## 도입부 스킵 — 2026-11-10

타이틀 맨 아래의 **튜토리얼을 스킵하고 새 게임 시작**은 기본 꺼짐이며 타이틀로 돌아오면 다시 꺼진다. 체크한 뒤 새 게임을 누르면 시작 스토리와 튜토리얼 화면을 생략하고 도입부 직후의 상태로 시작한다. 기존 거래 시스템으로 미래건설 첫 매수 1주·추가 매수 1주·매도 1주를 수행하고, 기존 턴 시스템으로 하루를 종료하며, 서지아의 일반 이벤트도 실제 AP를 소비해 첫 답변으로 처리한다. 자금·기업 이력·날짜·AP·관계·Memory를 기본 답변의 정상 진행과 동일하게 반영한다.

전체 스킵의 도입부 기본 선택은 서지아 **자금 상황 확인**, 강준혁 **장기 참여 검토**, 박도식 **작업량·일정부터 확인**이다. 이는 각 선택 장면의 `skipDefaultChoice = 0`이며 SO에서 제작자가 변경할 수 있다. 둘째 날 `inside_info_01`은 첫 답변인 **성과보수를 문서로 약속한다**를 처리한다. 플레이어에게 추가 선택 메뉴나 별도 보상을 제공하지 않는다.

대화창 왼쪽 위의 **스킵**은 암전 후 다음 미응답 선택지 또는 필수 조작·확인 목표로 이동하고 페이드인한다. 선택지를 자동으로 고르거나 필수 매수·매도·하루 종료를 대신 처리하지 않는다. 선택지와 필수 목표에서는 비활성 상태이며, 답변·목표를 완료하면 다시 사용할 수 있다. 일반 이벤트 진행 중에는 해당 이벤트의 기존 스킵 버튼을 사용한다. 선택 후 응답 대사를 생략해도 이미 반영한 관계·Memory를 재적용하지 않는다. 뒤에 선택지나 필수 목표가 없으면 남은 도입부를 마치고 자유 진행으로 복귀한다. 거래 실패 시에는 해당 조작 단계에 머물러 실제 성공 없이 완료 상태를 만들지 않는다.

가족이 피해를 보는 **마지막 납품·제안서·빈자리** 장면만 `showPlayer = false`로 설정했다. 주인공 대사와 가족·그룹 담당자의 대사에서도 성인 정장 스탠딩을 표시하지 않는다. 이후 성인 시기의 스탠딩은 기존 규칙대로 유지한다.

## 일반 이벤트 대화 스킵 — 2026-11-10

기존 7개 일반 이벤트의 협상 대화에도 왼쪽 위 **스킵**을 표시한다. 일반 이벤트의 첫 질문은 선택지가 즉시 함께 표시되는 구조이므로 이때는 버튼이 비활성 상태다. 미응답 선택지를 자동으로 고르지 않는다.

주가조작 제안처럼 다음 회사 선택으로 이어지는 응답 대화는 스킵 시 암전 → 회사 질문/선택지 준비 → 페이드인 순서로 넘긴다. 마지막 선택 이후 더 이상 선택지가 없으면 암전 중 대화를 닫고 일반 화면으로 페이드인한다. 정상 진행의 응답 연출과 닫기 버튼도 유지한다.

스킵은 이미 확정된 효과를 다시 호출하지 않는다. 기존 EventSystemController가 AP·선택 이력·현금/주식 효과·NPC 관계/기억을 처리하며, 스킵은 화면 전환과 기존 다음 단계/종료 콜백만 수행한다. 전환 중 연속 스킵을 차단하고, 외부 닫기·씬 전환 시 대기 중인 전환을 취소한다.

검증은 `EventDialogueSkipVerification.Run`: 7개 이벤트/17개 선택지를 정상 진행과 각각 비교하고 전체 게임 상태가 같은지 검사한다. 결과 및 최신 실행 파일은 workspace `QA_EventDialogueSkip/RESULT_KO.md`, `QA_EventDialogueSkip/Build/TakeOver.exe`다.

## 실제 게임 연결

도시맵에서 미래건설 선택 → 회사 정보·실제 자금과 주가 안내 → 실제 1주 매수 → 강준혁 면담·인물 정보 → 박도식 현장 대화·기억 확인 → 기존 하루 종료 버튼 → 둘째 날 서지아의 실제 이벤트 카드·AP·협상 → 실제 결과·기억 확인 → 미래건설/하늘식품 재무 비교 → 지분 확인 → 1주 추가 매수 → 1주 매도 → 매도 후 지분 확인 → 자유 진행.

매수는 기존 상세 패널과 ShareTradingSystem을 사용한다. 취소·잔액 부족·잘못된 수량에서는 진행하지 않는다. 성공 시 보유 주식 증가와 실제 현금 차감을 확인하며 연속 매수로 여러 번 처리되지 않게 한다. 주식 매수와 경영권 취득, 회사 운영자금 공급을 구분해 설명한다. 선택지의 효과는 기존 NPC 채널·처리기·기억 서비스에 전달한다.

컷신과 인물 확인 중에는 게임 뒤쪽의 클릭, 거래, 일반 이벤트 진입, 임의 턴 진행을 차단한다. 조작 단계는 금색 테두리 영역을 사용할 수 있다. 일반 이벤트는 지정된 서지아 카드와 협상 단계에서만 허용한다. 첫날 하루 종료는 기존 GameTurnClock을 딱 한 번 진행한다. 도입부의 대사·페이드·선택 자체로 AP와 날짜를 소비하지 않으며, 실제 일반 이벤트의 만남 시작에는 기존 AP 비용을 소비한다. 거래·하루 종료도 기존 게임 규칙을 따른다.

세 가지 대화에는 총 9개의 선택 결과가 있다. 새 결과는 Custom Memory로 별도 기록한다. 고용 유지 약속은 약속으로 기록하며 이미 회사를 구했거나 약속을 이행했다고 분류하지 않는다. 기록의 관계 수치는 초기 튜토리얼 밸런스이며 기존 이벤트 선택지의 기본값은 유지한다. Memory는 기존 저장·턴 만료 규칙을 따른다. 계약 이행·엔딩 판정과 도입부 중간 저장/재개는 이번 진행기의 기능 범위에 포함되지 않는다.
