# Assets 작업 지침

상위 `../AGENTS.md`와 workspace `../../psm/AGENTS.md`를 따른다. 에셋은 기능별 팀 폴더를 사용하고, 통합 플레이 씬은 `Scenes/Game.unity`다.

Unity 에셋을 이동·이름 변경·삭제하기 전 관련 프리팹 참조와 `.meta` GUID를 확인하고 보존한다. 이벤트 구독에는 해제 시점을 두며, UI가 데이터 상태를 직접 변경하는 대신 브리지/서비스를 사용하도록 한다. 검증 여부는 실제 수행한 범위만 기록한다.

## 팀 프리팹 작업 범위

- 팀별 폴더가 재정리될 수 있으므로 최신 연결 가이드와 실제 NPC 팀 소유 경로를 작업 전에 확인한다.
- `Scenes/Game.unity`는 플레이만 하고 저장하거나 수정하지 않는다. 새 작업 씬을 만들지 말고 NPC 팀 소유 프리팹에서 작업한다.
- 다른 팀 폴더·프리팹·씬은 열거나 수정하지 않는다. 타 팀 컴포넌트를 Inspector에 연결하지 말고, 연결 가이드에 따라 NPC 코드에서 `FindFirstObjectByType`로 찾는다.
- NPC 팀 소유 여부나 연결 방식이 불명확하면 추측해 에셋을 변경하지 않는다.
