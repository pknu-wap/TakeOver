# 이벤트 연출과 설명창 검수

- 기존 사건 그림이 있는 경우 해당 썸네일·상세 이미지를 재사용한다. 대응 그림을 찾지 못하면 기존 미래건설 제보 그림을 임시로 사용한다.
- 새 캠페인의 확인 전용 장면 9편은 ‘계속’으로 진행한다. 기존 선택 순서와 결과를 유지하기 위해 내부 완료 기록은 보존한다. 실제 분기가 있는 장면은 버튼에 의도, 대사창에 주인공의 발언과 상대의 응답을 표시한다.
- 이벤트 만남 진입과 종료에는 검은 화면을 사이에 둔 페이드를 적용했다. 튜토리얼 전체 스킵 중 실행되는 내부 조작은 화면 표시 없이 처리한다.
- 배드엔딩 14갈래는 기존 배경을 재사용하는 세 막의 내레이션으로 구성했다. 스킵은 다음 막으로 이동한다. 실패 조합과 재도전 준비 저장은 기존 규칙을 사용한다.
- 도움말 12개 항목과 튜토리얼 설명을 줄였다. 설명창과 해당 버튼은 기존 이벤트 상세창의 어두운 네온 그림을 재사용한다.

Windows 1280×720에서 40일차 사건의 썸네일·상세 그림, 주인공 발언과 김하린 응답, 진입·복귀 페이드를 확인했다. 5일차 실패 저장을 불러와 인물·진행률 없이 현장 배경과 내레이션을 읽고, 다음 막에서 사무실 배경으로 넘어가는 것도 확인했다.

Unity 통합 검수는 4,740건 통과했다. 네 시드의 42일 흐름, 14개 배드엔딩과 저장·재도전, 반복 사건 27편의 선택 결과 75개, 192일 반복 시험을 포함한다. 이미지·대사·도움말·엔딩 데이터 검사는 574건, 별도 엔딩 집중 검사는 623건 통과했다. 각 검사 수치는 별도로 기록한다.

최종 Windows 개발 빌드는 오류·경고 0건이며 빌드 콘텐츠 1,449건과 도움말 40건을 통과했다. 최종 실행 파일에서 새 게임 전체 스킵, 보상창 확인, 도움말 열기, 메인 투자 목표 항목까지 실제 클릭으로 확인했다. 검수용 빌드와 로그는 `QA_PresentationRevision/Final`에 있다.
