# 작업 중 실수와 재발 방지

## 2026-10-30 병합 충돌 검증

- 병합 중 `git ls-files`의 같은 경로가 여러 번 나오는 것을 고려하지 않아 GUID 중복을 잘못 감지했다. 검증 대상 경로를 먼저 중복 제거하고 재검사했다.
- Unity 프로세스 식별 중 전체 명령줄을 출력하여 인증 인자까지 출력했다. 이후에는 PID·실행 파일·프로젝트 경로 일치 여부만 출력하고 전체 명령줄은 출력하지 않는다. 인증 값은 이 문서에 기록하지 않는다.
- 임시 Unity 검증기에서 로드된 씬이 없는 초기 화면에도 `RestoreSceneManagerSetup`을 호출해 복원이 실패했다. 유효한 활성 씬이 있을 때만 복원하고, 없으면 빈 씬을 열도록 보정한다.
- 위 보정에서 `NewScene`에 `OpenSceneMode`를 잘못 전달했다. `NewSceneMode.Single`로 수정하고 임시 검증기도 Unity API의 인자 타입을 확인한다.
