# 초반 42일 캠페인과 배드엔딩 안내

2026-11-18. 현재 새 게임의 진행을 설명하는 요약본이다. 구현·저장 버전은 [실행 현황](PAIRED_CAMPAIGN_RUNTIME_KO.md), 긴 대사는 [교차 메인 원고](EARLY_STORY_PAIRED_EXPANSION_KO.md)와 [배드엔딩 원고](EARLY_STORY_BAD_ENDINGS_KO.md)를 따른다. 추가 작업과 재검수 결과는 [후속 작업 검토](EARLY_CAMPAIGN_REVIEW_KO.md)에 정리한다.

## 전체 구조

첫 등장 순서는 **미래건설 → 하늘식품 → 동방물산 → 한성공업**이다. 이후에는 두 기업 간격을 두고 **미래건설–동방물산 / 하늘식품–한성공업**을 묶어 이야기를 이어간다. 앞 기업의 문제가 뒤 기업을 접하는 이유가 되고, 첫 면담 이후에도 현재의 운영 계획을 결정하는 후속 이야기가 남는다.

| 기간 | 주요 진행 | 판정일 시작에 필요한 지분 |
|---|---|---|
| 1~6일차 | 튜토리얼·무소속 인물 소개, 미래건설 협력 제안, 남은 정산 부담 | **5일차 미래건설 10%** |
| 7~13일차 | 하늘식품 접촉, 제품 가치와 판매·회수 조건의 차이 | **12일차 하늘식품 10%** |
| 15~21일차 | 동방물산 접촉, 미래건설의 공사 인계와 동방의 운영 대기 대조 | **20일차 미래건설 30% + 동방물산 10%** |
| 23~29일차 | 한성공업 접촉, 하늘식품의 제품 전환과 한성의 생산·전수 검토 | **28일차 하늘식품 30% + 한성공업 10%** |
| 29~33일차 | 미래건설 비용·수주안과 동방물산 물량·인원 운영안, 첫 번째 쌍 마무리 | **32일차 미래건설 30% + 동방물산 20%** |
| 34~41일차 | 하늘식품 제품·회수안과 한성공업 생산·전수안, 두 번째 쌍 마무리 | **40일차 하늘식품 30% + 한성공업 20%** |
| 42일차 | 네 기업 기록 종합, 다음 조사·협상 준비의 우선순위 선택 | 추가 지분 조건 없음 |

새 목표 안내일은 7/15/23/29/34일차다. 32일차 목표는 21일차에, 40일차 목표는 29일차에 미리 예고한다. 14·22일차처럼 새 필수 장면이 없는 날도 있으며 그동안 거래·일반 사건을 진행할 수 있다.

미래건설의 첫 협력 제안은 기존처럼 미리 완료할 수 있다. 다른 본편은 지분을 일찍 확보해도 예정된 일차 전에 열리지 않는다. 42일차까지 확인하는 것은 **APEX의 사업 개입**이다. 구체적인 위반 실행 기업·담당자·상위 지시는 중반 조사로 남긴다.

## 두 기업을 연결하는 내용

### 미래건설–동방물산

미래건설은 공사를 끝냈지만 장비·정리 비용과 지급 부담이 남아 있다. 동방물산은 거점을 준비했지만 예정된 물량을 받지 못했다. 두 회사가 공유에 동의한 날짜와 설명을 비교하며 ‘현장 인계가 잘못됐다’는 설명만으로는 부족함을 알아간다.

현재의 문제도 함께 진행한다. 강준혁은 새 수주로 회사를 움직이려 하고, 서지아는 과거 비용을 다음 공사 수익과 분리하려 한다. 박도식은 실제 현장 정리를 짚는다. 강재현은 확장을 서두르지만 박민우는 확정 물량과 예상 물량, 이동할 사람들의 부담을 구분한다. 32~33일차에는 두 회사가 각자의 수정안을 마무리한다.

### 하늘식품–한성공업

하늘식품은 어떤 제품을 남길지와 회수 조건을, 한성공업은 그것을 반복해서 만들 생산 기반과 숙련 전수를 검토한다. 두 회사가 원래 거래했다는 전제를 넣는 것이 아니라 새로운 대응 가능성을 살피는 과정이다.

김하린은 기존 손님과 품질을, 오재성은 전환 비용과 실제 현금 회수를 본다. 조민석은 생산 기술을 지키려 하고, 최미정은 다음 사람이 그 기술을 이어받을 시간을 요구한다. 40~41일차에는 제품·회수·납기·전수를 함께 놓고 각 회사의 현재 계획을 정리한다. 실제 공급 계약과 자금 집행은 별도 절차다.

## 투자 목표와 필수 사건 묶음

20일차 판정이라면 **19일차를 마치기 전에** 지분을 준비한다. 20일차 시작의 날짜·경제 갱신이 끝난 뒤 실제 보유 비율을 확인한다. 두 조건은 모두 필요하며 한 회사의 초과 지분으로 다른 회사의 부족을 대신할 수 없다.

20·28·32·40일차에 성공하면 해당 두 회사의 필수 카드만 표시한다. 읽는 순서는 자유다.

1. 카드 하나를 열어 대사와 답변, 결과 대사까지 마친다.
2. 완료한 카드는 빠지고 다른 필수 카드 하나가 남는다.
3. 두 사건을 모두 마치면 원래 일반 사건 화면으로 돌아간다.

진행 중에는 거래와 날짜 진행이 잠긴다. 하나를 마친 뒤 저장하면 남은 사건부터 이어지며 완료한 효과·기억을 다시 적용하지 않는다. 새 필수 사건은 AP 0이고, 기존 미래건설 첫 협력 제안은 AP 1을 유지한다. 다음날 공동 장면에서는 두 설명을 대조하거나 현재 계획을 마무리한다.

과거에 잠깐 목표를 달성했던 것만으로 면제되지 않는다. 예를 들어 20일차 미래건설 30%를 달성했어도 32일차에 다시 확인한다. 이미 확보한 지분은 그대로 인정하므로 매번 같은 양을 추가 매수하라는 뜻은 아니다. 첫 미래건설 협력 제안을 조기에 완료한 경우에는 5일차에 다시 실패시키지 않는다.

## 배드엔딩이 발생하는 방식

5/12/20/28/32/40일차 시작에 목표가 미달하면 그 시점의 성공 장면을 진행하지 않고 해당 실패로 들어간다. 현재는 협력 보류·거절 같은 대사 선택 자체로 배드엔딩을 판정하지 않는다.

복수 목표는 **앞 기업만 미달 / 뒤 기업만 미달 / 양쪽 미달**을 구분한다. 단일 목표 2갈래와 복수 목표 12갈래를 합쳐 14개다. 미달 회사 전체와 실제 지분을 기록하고 각 갈래의 고유 신호를 한 번 전달한다.

| 판정일 | 미달 조건 | 주인공 회사의 최종 결과 |
|---|---|---|
| 5 | 미래건설 10% | 첫 사업 성립 실패, 후속 출자 중단, 회사 청산 |
| 12 | 하늘식품 10% | 업종 확장 중단, 자산 보유 법인 전환, 주인공 퇴임 |
| 20 | 미래건설 30%만 | 재편 사업 폐지, 운용 이관, 대표 위임 종료 |
| 20 | 동방물산 10%만 | 신규 발굴 사업 폐쇄, 새 대표 선임 |
| 20 | 양쪽 모두 | 회사 해산과 잔여 자산 정리 |
| 28 | 하늘식품 30%만 | 수요와 생산의 연계 실패, 독립 투자 업무 종료 |
| 28 | 한성공업 10%만 | 다른 투자회사에 흡수, 대표 직위 소멸 |
| 28 | 양쪽 모두 | 회사 매각, 창업자 퇴임 |
| 32 | 미래건설 30%만 | 대표 교체, 창업자 지분 정리 |
| 32 | 동방물산 20%만 | 투자 결정권 회수, 대표 퇴임 |
| 32 | 양쪽 모두 | 외부 조직 통합, 독립 회사 소멸 |
| 40 | 하늘식품 30%만 | 사업·자산 매각으로 방향 변경, 새 경영진 선임 |
| 40 | 한성공업 20%만 | 회사 지배권과 운용 업무 이전 |
| 40 | 양쪽 모두 | **APEX에 회사 인수, 주인공의 대표 권한 종료** |

마지막 연락을 받는 투자 대상 기업이 반드시 파산하는 것은 아니다. 엔딩은 **대상 기업의 결정 → 주인공 회사의 사업·출자 심사 → 회사 정리나 대표 교체 → 주인공의 퇴장**까지 보여준다.

주인공은 외부 공동출자와 단계별 사업 검토를 바탕으로 작은 투자회사를 시작했다. 이 전제를 도입부부터 보여주므로 회사에 현금이 남아 있어도 공동출자자들의 사업 방향 변경과 대표 교체로 독립 운용이 끝날 수 있다. 숨은 대출이나 즉시 지급불능을 사후에 만들어내지 않는다. 별도의 법인 지분 거래·급여·임대료 차감 기능이 추가된 것은 아니다.

가장 늦은 동시 실패는 가족 회사를 잃은 뒤 맞서려고 세운 자기 회사마저 APEX의 보유 자산이 되는 결말이다. 이 인수는 시간 경과 뒤의 현재 거래이며 과거 범죄 지시의 증거를 추가로 공개하는 장면은 아니다.

## 재도전과 이어하기

| 실패 판정 | 재도전 준비 저장 |
|---|---|
| 5일차 | 튜토리얼 완료 후 2일차 |
| 12일차 | 7일차 접촉 완료 후 |
| 20일차 | 15일차 접촉 완료 후 |
| 28일차 | 23일차 접촉 완료 후 |
| 32일차 | 29일차 공동 장면·목표 안내 완료 후 |
| 40일차 | 34일차 목표 안내 완료 후 |

엔딩의 **재도전**은 별도로 저장한 준비 시점의 전체 상태로 돌아간다. 이후 거래·경제·기억·사건도 함께 되돌리며 부족 지분이나 자금을 무료로 추가하지 않는다. 정상적인 준비 저장이 있을 때만 버튼을 표시한다.

타이틀의 **이어하기**는 최신 자동 저장을 읽는다. 실패 상태를 저장했다면 같은 엔딩의 읽던 위치를 이어본다. 재도전 후에는 복원된 정상 상태를 다시 자동 저장한다. 저장 실패 대기 중에는 다음 날짜로 넘어가지 않으며, 저장 재시도는 이미 끝난 정산을 반복하지 않는다.

## 일반 사건·그린메일·기존 저장

- 회사 반복 서브는 해당 회사 첫 본편 면담 이후 개방한다. 메인 단서를 얻기 위해 반복 서브를 필수로 볼 필요는 없다.
- 그린메일은 미래건설·동방물산이 **33일차 공동 마무리 이후**, 하늘식품·한성공업이 **41일차 공동 마무리 이후** 후보가 된다. 42일차 종합에는 추가 지분 조건이 없다.
- 그린메일 수락은 전량 매도와 해당 기업의 영구 재매수 금지다. 아직 본편이 없는 신규 다섯 기업은 잠겨 있다.
- 이 안내는 **새 게임** 기준이다. 기존 이벤트 v1~v5 저장은 종전 29일차·각 회사 10% 진행표로 이어간다. 최신 조건을 과거 저장에 소급하지 않는다.

## 현재 검증 범위

기존 통합 검수는 Play 6,645 PASS / 0 FAIL, 빌드 콘텐츠 1,421 PASS / 0 FAIL과 Windows 빌드 성공을 기록했다. 네 시드 실제 매수로 42일차 진행, 14개 실패, 사건 묶음 중간 저장, 재도전, 기존 저장, 반복 27편·75개 결과를 포함한다. 완료 QA 정리 후에도 남는 수치와 범위는 [검증 기록 보존본](CAMPAIGN_VALIDATION_KO.md)을 따른다.

이번 문서화와 재검수에서 발견한 보완 사항은 별도의 [검토 문서](EARLY_CAMPAIGN_REVIEW_KO.md)에 기록한다. 이전 검수 수치를 이번 추가 검사의 실행 횟수로 합산하지 않는다.
