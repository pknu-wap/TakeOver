신규 세 회사는 미리 10%를 확보해도 본편이 앞당겨지지 않는다. 조건이 충족된 판정일에는 해당 필수 사건만 제시하고 완료 후 다른 사건을 복원한다. 각 새 필수 대화는 0 AP다. 미래건설 기존 협력 제안의 1 AP는 유지한다. 대화·결과를 마치지 않은 상태에서 다른 날짜로 넘길 수 없다.

회사 서브 개방은 투자 미션을 받았다는 사실보다 늦은 **첫 본편 면담 완료**를 기준으로 삼아 기업 인물의 첫 대면 연출을 보존한다. 그린메일은 회사의 후속 메인까지 완료해야 한다. 현재 메인이 등록되지 않은 신규 다섯 회사에는 그린메일이 열리지 않는다. 기존 그린메일의 매도·웃돈·영구 재매수 금지 효과는 그대로다.

초반의 마지막 확인은 APEX Corp의 사업 개입이다. 특정 위반 실행·가담·상위 지시 입증은 중반으로 남긴다. 29일차 네 회사 우선순위 선택은 추가 인수나 자금 집행이 아니다.

| 실패 단계 | 신호 |

모두 기존 미래건설과 같은 페이드아웃·입력/날짜 잠금·검은 화면 완료 후 전달 경로다. `BadEndingRequested`와 Inspector UnityEvent에 사건·회사·실제 판정일·지분·신호를 전달한다. 같은 실행에서는 한 번, 실패 저장을 새로 복원한 실행에서는 같은 신호를 한 번 재전달한다. 실제 엔딩 화면 담당자는 기존 `ReleaseDeadlineCurtainForEnding()`을 사용할 수 있다. 단계별 엔딩 장면 자체를 이 작업에서 새로 작성한 것은 아니다.

## 콘텐츠와 화면

- `StoryEventDatabase`: 기존 미래건설 1건 + 접촉·후속·기업 본편 10건 = 11건.
- `GeneralEventDatabase`: 반복 정의 21종 + 외부 첫 연락 4종 + 특수 일반 사건 그린메일 1종 = 26종.
- 경영진/구조조정의 회사별 본문·선택 변주를 포함해 반복 서브는 27편, 선택 결과는 75개다.
- `IntroSequence`: 230개 항목, 대화 선택 7곳·21개 선택지. 기존 필수 조작 14개와 첫 매수·추가 매수·매도·날짜·5% 보상을 유지한다.
- 복수 인물의 발언·플레이어 대사·독백·결과 대사는 원본 이벤트 UI의 공용 렌더러로 페이지를 넘긴다. 스킵은 선택지 앞에서 멈추고 선택 효과를 다시 실행하지 않는다.
- 미션이 없을 때 기존 목표 바의 전체 폭 중앙에 `지금은 투자를 고려할 회사가 없다`만 표시한다.
- 홈은 기존 5장 배치를 유지하고, 활성 사건이 5개를 넘어도 좌우 회전으로 모두 접근한다. 카드 정렬은 게임의 무작위 상태를 소비하지 않는다.
- 설명은 도움말의 `메인 투자 목표·반복 만남`에 추가했다. 새 설명 사진은 미확보로 비워둔다.

대본을 수정한 뒤 `python Tools/StoryExpansion/build_authoring.py`로 저작 JSON을 생성하고, Unity의 `TakeOver/Story/Build Early Campaign and Repeatable Events`를 실행한다. 이 빌더는 NPC·기업 재무·원본 이벤트 UI 프리팹·씬을 재생성하지 않는다. 기존 공통 사건의 ID와 정상/암전 스탠딩 참조를 유지한다.

## 반복·기억·경제 효과

날짜 갱신 완료 후 대상별 20%를 판정하고, 적격 사건 중 하나를 선택한다. 하루 신규 반복 제안 최대 2개, 같은 대상 활성 반복 제안은 1개다. 공통 정의는 여러 회사가 같은 날 동시에 골라도 활성 ID가 중복되지 않게 한다. 일반 대기는 D+3, 구조조정 D+7, 주가조작·정치 후원 D+10이며 미응답 만료는 기존 7일 대기를 유지한다.

회차별 고유 ID와 이력을 저장한다. 동일 선택 확정·결과 닫기·로드로 NPC 기억·현금·예약 경제 효과를 중복 적용하지 않는다. 최신 답변과 과거 회차는 분리한다. 정치 후원의 기준 완화는 과거 수락 사실로 유지하고 후속 거절이 과거 수락을 없애지 않는다. 실제 법률이 바뀌었다고 설명하지 않는다.

새 일상 사건은 관계·관찰 기억 중심이다. 구조조정의 이번 검토 의견을 실제 해고·배치·고용 보장 완료로 처리하지 않는다. 주가조작은 실제 보유·소개된 회사 중 조건을 만족하는 종목을 선택하고 기존 다음 턴 급등 효과를 적용한다. 매도 수익은 보장하지 않는다.

## 저장·이어하기

전체 저장 형식은 v4, 이벤트 섹션은 v5다. 기존 NPC·거래·플레이어 기억·AP와 함께 현재 필수 사건·실패 대상·진행 선택·반복 회차·당첨 제안·대기일·정치 후원 사실을 보존한다. 결재의 미처리/완료/읽음 기록과 뉴스도 저장한다. 로드는 경제·날짜·선택 효과·무작위 추첨을 다시 실행하지 않는다.

타이틀 이어하기는 저장 파일이 있을 때 활성화된다. 명시적 이어하기 요청은 튜토리얼을 실행하지 않는다. 새 게임은 기존 튜토리얼 경로를 사용한다. 자동 저장 시점은 튜토리얼 완료 이후의 하루 시작과 만남 종료다. 튜토리얼 중간·미응답 대화 도중은 저장하지 않는다. 전환 중 실패는 검은 화면과 전달 준비가 끝난 뒤 저장한다.

저장 실패로 재시도할 사본이 있으면 다음 날짜로 진행하지 않는다. 하루 마감 재시도는 저장 사본만 기록하며 이미 끝난 날짜 계산·경제·선택을 다시 실행하지 않는다. 이어하기 실패는 공용 이벤트 양식의 안내 후 확인으로 타이틀에 돌아가며 잘못 복원된 상태로 진행하지 않는다.

v2/v3 전체 저장은 당시 존재하지 않았던 뉴스·결재 구역을 빈 상태로 추가한다. 저장되지 않았던 과거 기록을 복구했다고 주장하지 않는다. 이벤트 v1~v4는 기존 선택과 상태를 보존하며, 기존 미래건설을 이미 마치고 6일차를 넘긴 저장은 신규 회사 일정만 `저장 일차 - 6`일 뒤로 이동시킨다. 새 스토리를 과거에 완료한 것으로 추정하거나 불러오자마자 이미 지나간 신규 기한으로 실패시키지 않는다.

자동 검증은 격리 경로를 사용한다. 일반 배치 검증은 개인 저장을 자동 덮어쓰지 않으며, 명시적인 검증 저장 경로를 지정한 세션만 해당 경로에 기록한다.

## 검증

현재 통합 Play 검증: 3,220 PASS / 0 FAIL. 실제 거래로 4개 시드의 29일차까지 네 기업 목표·메인을 완료했고, 모든 시드에서 자금이 남았다. 네 실패 신호·실패 복원, 타이틀 이어하기, 결재/뉴스와 반복 회차 복원을 확인했다. 반복 27편·75개 선택의 실제 NPC 연결을 검사했다.

192일 반복 스트레스 관측은 보유 지분·실적·소비자 반응을 조정한 적격 조건 시험이다. 210건이 발행됐고 논리 대본 27편 중 26편을 관측했다. 전체 27편의 모든 선택 실행 여부는 별도의 75개 결과 검사에서 확인했다. 일반 플레이의 자연 발생률로 해석하지 않는다.

확장 튜토리얼 정상 UI 진행 1,652 PASS, 전체 스킵의 정상 결과 일치와 대화 스킵 62 PASS, NPC Play 회귀 264 PASS, 6개 사건의 양방향 카드 접근 18 PASS, 자동 저장·실패 재시도·실제 이어하기·구버전 변환·손상 저장 거절 11 PASS를 확인했다. 위 통합 검증과 합쳐 5,227 PASS / 0 FAIL이다. 네 기업의 실패는 검은 화면 완료·개별 신호·복원 후 재전달까지 검사했다.

Windows 64비트 개발 빌드는 성공했고 오류·경고는 0건이다. 빌드 콘텐츠 검사 833 PASS도 확인했다. 결과와 캡처는 루트 `QA_Campaign` 및 개인 요약에 기록한다. 이 검증은 초반 실행 흐름과 회귀 검사이며 중반 다섯 기업의 실제 본편이나 단계별 배드엔딩 장면 제작까지 포함하지 않는다.
