# Windows 실행 파일 사이클 검수 — 2026-11-18

기준 `69d7cb8` 및 이번 미커밋 수정. Unity 6000.3.6f1 Windows64 개발 빌드를 1280×720 창으로 실행하고 Computer Use의 실제 마우스·키보드 입력으로 확인했다. 개인 저장 대신 `TAKEOVER_SAVE_DIRECTORY`로 루트 `QA_WindowsCycle/save-*`를 사용했다.

## 판정

확인한 성공·실패·복원 사이클은 정상 진행됐다. 타이틀 이어하기 버튼 미연결과 튜토리얼 보상 직후 기업 목록 지분 미갱신을 발견해 수정·재검수했다. 일부 사건의 스탠딩 이미지 비율과 상세창 가독성 결함은 남아 있다. 전체가 무결하다는 판정은 아니다.

## 발견 및 수정

1. **타이틀 이어하기 클릭 무반응 — 수정 확인.** MainMenuController는 씬 루트에 있고 ContinueButton은 별도 Canvas 아래에 있다. 자식만 검색하던 코드가 버튼을 찾지 못해 클릭 리스너·저장 유무에 따른 활성 상태를 설정하지 못했다. 같은 씬의 루트에서 버튼을 검색하도록 수정했다. 실제 재실행·타이틀 클릭으로 엔딩의 읽던 대사와 필수 카드 하나가 남은 상태를 각각 복원했다.
2. **튜토리얼 보상 직후 기업 목록 지분이 이전 값 — 수정 확인.** 목표 바는 5.1%인데 오른쪽 목록은 0.1%였고 날짜 진행 후에만 갱신됐다. DashboardCompanyPanel을 사건 목록 변경 알림에도 연결했다. 수정 빌드의 전체 스킵 완료 직후 날짜를 넘기지 않은 상태에서 목표 바·기업 목록 모두 5.1%임을 확인했다.

기존 SessionSaveVerification은 `startContinue()`를 직접 호출해서 실제 버튼 미연결을 놓쳤다. 이제 실제 ContinueButton을 찾아 활성 상태를 검사하고 버튼의 onClick으로 복원한다. 수정 후 해당 저장·복원 회귀 **15 PASS / 0 FAIL**. 이는 모든 화면의 실제 좌표 클릭을 자동 검사한다는 뜻은 아니다.

## 남은 표시 문제

- **사건 카드·상세창 스탠딩 사용 문제:** 강재현·김하린·최미정 등 스탠딩이 카드에서 가로로 늘어나 보인다. 상세창에서는 투명 스탠딩이 기존 전체 배경 이미지 자리에 표시되어 배경 패널이 사라지고 제목·설명이 인물 및 뒤 화면과 겹친다. 버튼 입력과 대화 진입은 가능하지만 상세 본문 가독성이 나쁘다. `StoryExpansionBuilder.AddArt()`가 기존 사건 그림을 찾지 못하면 standing을 cardImage와 image 양쪽에 넣는 경로와 `EventDetailView.show()`의 hasArt 판정이 연결돼 있다. 이번 수정 대상에는 포함하지 않았다.
- **정수 금액 표시의 혼동:** 낮은 주가가0으로 표시되거나 소액 거래 전후 잔금이 같은 정수로 보일 수 있다. 실제 매수·매도와 지분 변경은 진행됐고 저장 현금은 소수 금액을 보존했다. 현재 정수 표시 정책과 단위의 문제로 기록하며 무료 거래·계산 오류로 판정하지 않는다.
- 인물 정보창 관계 수치와 막대 간격이 좁아 보이는 관찰은 있었으나, 이번 검수에서 별도 레이아웃 수정·다중 해상도 판정은 하지 않았다.
