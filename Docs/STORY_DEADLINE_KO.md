# 미래건설 필수 스토리 기한

- 대상: 「미래건설의 협력 제안」, 기존 ID `inside_info_01`.
- 목표 바: 상단바 왼쪽 아래에 상단바의 실제 배경·글꼴을 복제한다. 칸 비율 7:4, 왼쪽 `미래건설의 지분 10% 이상 인수하기`, 오른쪽 `앞으로 n일`. n은 `max(0, 5 - 현재 일차)`다. 튜토리얼 중에는 숨기고 정상 완료/전체 스킵 후 표시하며, 필수 사건을 완료하면 제거한다.
- 5일차 시작에 이미 사건을 완료했다면 일반 진행을 유지한다. 이후 매도했다고 다시 실패시키지 않는다.
- 미완료라면 그 시점의 실제 보유 지분으로 판정한다. 10% 미만은 즉시 실패 상태로 잠그고 페이드아웃한다. 과거에 잠시 10%를 확보했던 사실만으로 면제하지 않는다.
- 10% 이상이면 해당 카드 하나만 표시한다. 다른 이벤트는 완료·삭제·재추첨하지 않고 원래 발생 회사·최초 날짜·기한을 유지한 채 숨긴다. 결과 확인 후 대화를 닫으면 기존 카드 목록을 복원한다. 세 선택 중 어떤 선택으로 마쳐도 필수 진행은 완료된다.
- 필수 진행 중에는 `ITurnAdvanceGuard`로 날짜 진행을 막는다. 이벤트의 AP 1은 기존 시작 경로에서 한 번만 사용한다. 일반 화면에서 사건을 열어 시작하며 자동 답변하지 않는다.
- 이 사건은 일반 제안의 발생 후 2일 만료·7일 대기 정책 대신 고정된 5일차 기한을 사용한다. 5일차 이전에도 10%를 확보하면 같은 날짜에 카드를 확인할 수 있다. 목록 복원은 날짜를 넘기거나 효과를 재지급하지 않는다.

## 배드엔딩 연결부

`EventSystemController.BadEndingRequested` C# 이벤트와 Inspector의 `On Bad Ending Requested`(`UnityEvent<string>`)를 제공한다. 화면이 완전히 검게 된 다음 한 번 전달한다.

- 신호 ID: `mirae-cooperation-deadline-failed`
- C# 전달 데이터: 대상 이벤트 ID, 회사 ID, 실패 기한 일차(5), 판정 시 지분율.
- 공개 상태: `MandatoryState`, `IsMandatoryFailureReady`, `LastDeadlineFailure`.
- 실제 엔딩 담당자는 신호를 받아 별도 엔딩을 표시한 뒤 `ReleaseDeadlineCurtainForEnding()`으로 전환용 검은 막을 제거한다. 실패 후의 일반 날짜 진행 잠금은 유지된다.

현재는 실제 배드엔딩 대본·장면을 만들지 않았다. 연결 전에는 페이드 완료 후 검은 화면과 실패 상태를 유지한다.

## 저장과 날짜 순서

이벤트 저장 v3에 필수 진행 상태와 실패 당시 지분을 보존한다. 강제 카드 상태를 로드하면 다시 그 카드만 표시한다. 실패 저장을 로드하면 즉시 검은 막을 복원하고 로드한 세션의 엔딩 담당자에게 한 번 신호를 전달한다. 전환 도중 저장은 거부한다.

v1/v2 저장은 기존 선택·결과·보상을 유지하며 완료 기록에서 필수 완료를 복원한다. 미완료인 과거 저장은 복원된 날짜와 보유량을 기준으로 기한 규칙을 적용한다. 지원하지 않는 버전이나 모순된 상태는 전체 적용 전에 거부한다.

`GameTurnClock.DayStarted`는 기존 `TurnAdvanced`의 모든 경제/시장/이벤트 갱신 뒤 호출한다. 기한 판정은 이 완료 지점에서 실행해 구독 순서나 갱신 전 지분 표시값에 의존하지 않는다. 원본 씬·상단바·이벤트 UI 프리팹은 수정하지 않는다.
