작성일: 2026-11-08

================================================================
1. 목표와 기본 구조
================================================================

새 게임을 시작하면 어두운 배경의 프롤로그가 나오고, 장면과 NPC 대화를 자연스럽게 전환하며 실제 게임 조작 튜토리얼로 이어지도록 한다.

전체 흐름:
새 게임 → 암전 및 초기화 → 과거 프롤로그 → 윤하진과 첫 만남 → 현재 사무실 → 미래건설 튜토리얼 → 다음 협상 예고 → 자유 진행

장면마다 Unity 씬을 따로 만들기보다 Game 씬 위에 스토리 연출 화면을 올리는 방식을 우선한다. 배경·대사·NPC 배치를 전환하고, 실제 게임 조작이 필요한 단계에서 해당 화면을 보여준다.

현재 새 게임 진입은 MainMenuController.startNewGame에서 Game 씬을 불러오는 방식이다. 여기에 새 게임의 도입부 시작 경로를 연결하는 방안을 검토한다. Game 씬을 직접 실행하는 개발·검수 경로와 기존 게임 진행까지 자동으로 도입부에 진입시키지는 않도록 구분한다.

================================================================
2. 장면 진행 계획
================================================================

단계 1. 새 게임 → 암전
- Game 화면이 먼저 잠깐 노출되지 않도록 처음부터 검은 화면으로 덮는다.
- 뒤에서 회사 데이터·NPC 레지스트리·화면 초기화를 완료한다.
- 초기화가 끝난 뒤 프롤로그를 시작한다.

단계 2. 어두운 배경의 프롤로그
- 대본의 P-01~P-04를 따른다: 마지막 납품 → 자산 양수 제안 → 빈 작업장 → 재기와 투자회사 설립.
- 지급 보류 통지, 계약서, 달력, 빈 작업장 등의 이미지와 독백을 활용한다.
- 클릭으로 대사를 진행하고 장면 사이에는 짧은 페이드를 넣는다.
- 가족·그룹 담당자·그룹 회장 등 외형과 이름이 확정되지 않은 인물은 문서·전화·실루엣 중심으로 표현한다.
- 초안의 제안 설정과 미정 사항은 확정된 세계관으로 임의 승격하지 않는다.

단계 3. 윤하진과 첫 만남 → 현재 사무실
- P-05에 따라 호텔 라운지에서 윤하진이 등장한다.
- 독백 중심 화면에서 NPC 대화 화면으로 전환한다.
- 윤하진의 거래 중심적 동기, 출처가 불분명한 정보와 주인공의 검증 태도를 보여준다.
- 미래건설을 소개하는 대화가 끝나면 페이드 후 현재 사무실·도시맵으로 이어진다.

단계 4. 미래건설 조사·재무 설명
- 도시맵에서 미래건설을 선택하도록 안내한다.
- 회사 정보와 플레이어 보유 자금을 실제 데이터로 보여준다.
- 서지아의 재무 설명과 질문 선택을 진행한다.
- 자금 사정·성장 가능성·가격 질문의 의미를 유지하며 가격 협상 자체를 악행으로 취급하지 않는다.

단계 5. 실제 소량 지분 매수
- 기존 거래 화면에서 수량·총액·남는 자금을 확인하고 매수한다.
- 버튼 클릭만으로 다음 단계로 넘어가지 않는다. 실제 매수 성공 및 보유 지분 반영을 확인한다.
- 매수 취소·실패·잔액 부족 시 해당 단계에 머문다.
- 튜토리얼 수량과 금액은 시작 자금 및 실제 거래 규칙에 맞춰 확정한다.
- 첫 지분 매수는 경영권 인수 완료가 아니다. 기존 주식 매수 대금이 회사 운영자금으로 바로 유입된다고 설명하지 않는다.

단계 6. 강준혁 면담
- 윤하진의 소개로 성립한 면담으로 이어진다.
- 장기 참여·수익 중심 투자·경영권 확보 의사를 묻는 기존 대본 선택지를 따른다.
- 인물 정보에서 강준혁이 중요하게 여기는 회사 정체성·계약·현장 인력을 확인하도록 안내한다.

단계 7. 박도식 현장 방문
- 현장 배경으로 전환하고 박도식을 표시한다.
- 현장 확인·고용 유지 약속·비용 검토 선택을 진행한다.
- 대화와 선택이 관계 및 Memory에 기록된다는 점을 안내한다.
- 고용 유지 약속의 기록과 실제 이행 판정은 구분한다. 약속한 시점에 이행했다고 간주해 보너스를 주지 않는다.
- 이후 경영 행동과 약속을 대조하는 기능은 별도 설계·구현 대상이다.

단계 8. 하루 종료 → 다음 협상 예고 → 자유 진행
- 기존 하루 종료 조작을 안내한다.
- 실제 턴 진행과 갱신된 회사 정보·보유 자산을 확인한다.
- 서지아의 다음 회의 연락과 윤하진의 다른 회사 소개를 보여준다.
- '도입부 완료 — 첫 번째 주주'를 표시하고 튜토리얼 제한을 해제한다.
- 미래건설의 후속 협상과 다른 회사 탐색을 선택할 수 있게 한다.

================================================================
3. NPC 출력과 전환 규칙
================================================================

- 장면 데이터에는 NPC ID를 지정한다. 이름·직책·기본 스탠딩·어두운 스탠딩은 기존 NPC SO에서 가져온다.
- 기존 NPC ID와 SO를 공통 원본으로 사용하고 대본용 인물 데이터를 중복으로 관리하지 않는다.
- 말하는 인물은 밝게, 듣는 인물은 어둡게 표시한다.
- 전환 시 이전 인물 표시를 정리하고 다음 배경·인물 배치를 준비한 뒤 화면을 밝힌다.
- 이전 장면의 NPC 이미지가 다음 인물의 대사에 잠깐 남지 않도록 이름·이미지·대사를 함께 갱신한다.
- 독백·문서 장면에서는 NPC 표시 영역을 숨긴다.
- 이미지가 없는 인물은 정해진 실루엣을 사용한다.
- 스탠딩의 원래 비율과 하단 기준 배치를 유지하며 해상도에 따른 잘림을 확인한다.
- 새로운 미정 인물의 ID·외형·이름을 임의로 확정하지 않는다.

================================================================
4. 구현 책임 분리와 제작자 편집
================================================================

아래 역할을 나누되 구체적인 클래스명과 에셋 형식은 구현 시 확정한다.

대본 데이터:
- 장면 순서, 배경, 등장 NPC, 화자, 대사, 선택지, 다음 장면과 진행 조건을 저장한다.
- 제작자가 Inspector에서 편집할 수 있도록 구성한다.

화면 연출:
- 어두운 배경, 페이드, 대사 표시, NPC 등장·퇴장·강조를 담당한다.
- 빠른 연속 클릭이나 장면 전환 중 입력으로 대사가 중복 진행되지 않게 한다.

스토리·튜토리얼 진행:
- 현재 장면과 목표를 관리한다.
- 회사 선택·정보 확인·실제 매수 성공·인물 정보 확인·턴 진행 등의 완료 조건을 확인한다.
- 하나의 완료 동작으로 여러 단계를 건너뛰지 않도록 단계별 처리를 한 번만 실행한다.

기존 거래·NPC·Memory·턴 기능은 기존 경로를 활용한다. 기존 일반 이벤트에 튜토리얼 장면을 무조건 끼워 넣기보다 필요한 표시·결과 전달 기능을 검토해 연결한다.

================================================================
5. 입력·시간·일반 이벤트 제어
================================================================

- 컷신 중에는 뒤쪽 게임 화면의 클릭과 임의 턴 진행을 막는다.
- 실제 조작 튜토리얼 단계에서는 필요한 화면·버튼만 사용할 수 있게 한다.
- 프롤로그 장면 전환만으로 게임 날짜가 지나거나 AP가 소비되지 않도록 한다.
- 매수·턴 종료 등 실제 게임 조작은 기존 규칙과 연결한다. 튜토리얼 AP 소비량의 세부 정책은 별도 확정한다.
- 일반 이벤트 노출·팝업이 도입부와 겹치지 않게 조절한다.
- 튜토리얼 종료 시 일반 화면과 이벤트 진행을 정상적으로 돌려놓는다.
- 신규 튜토리얼의 관계·Memory 효과는 장면 의미에 맞게 별도로 정의한다. 기존 이벤트 선택지나 현재의 Memory 보너스를 자동 변경하지 않는다.

================================================================
6. 권장 구현 순서
================================================================

1차 연결:
새 게임 → 암전 → 프롤로그 → 윤하진 → 미래건설 선택·재무 확인·실제 매수까지 연결한다.

2차 연결:
강준혁 면담 → 인물 정보 안내 → 박도식 현장 방문 → 관계·Memory 확인을 연결한다.

3차 마무리:
하루 종료 → 다음 협상 예고 → 자유 진행을 연결하고 일반 게임 기능 복귀를 검증한다.

각 단계에서 NPC 출력·입력 제어·진행 조건을 확인한 뒤 다음 범위를 붙인다.

================================================================
7. 구현 시 검증 항목
================================================================

- 새 게임 첫 화면에서 대시보드나 일반 이벤트가 먼저 노출되지 않는가.
- 장면 전환·대사 진행·선택지 연속 클릭에서 중복 실행이나 멈춤이 없는가.
- 화자 이름·직책·NPC 이미지가 일치하고 이전 인물의 잔상이 남지 않는가.
- 독백·문서·미정 인물 장면에서 NPC 영역이 올바르게 처리되는가.
- 실제 매수가 성공해야 다음 단계로 진행되는가.
- 취소·잔액 부족·실패 상황에서도 재시도할 수 있는가.
- 튜토리얼 도중 불필요한 날짜·AP 변화나 일반 이벤트 개입이 없는가.
- 마지막 턴 진행이 한 번만 반영되고 자산·회사 정보·AP·달력이 정상 갱신되는가.
- 튜토리얼 완료 후 입력 제한이 풀리고 일반 게임 진행이 가능한가.
- 현재 NPC ID·SO·이벤트 연결·관계·Memory 저장 흐름이 유지되는가.
- Unity Play 모드와 Windows 빌드에서 새 게임부터 자유 진행까지 이어지는가.

8. 현재 작업 상태
================================================================

이 파일은 논의한 계획을 정리한 문서다. 이번 저장 요청으로 게임 코드·씬·프리팹·NPC 데이터는 변경하지 않는다. 실제 구현과 세부 수치 확정은 후속 작업이다.

9. 메인 스토리 대립 기업 5곳 — 최종 선정본
================================================================

추가일: 2026-11-09
사용자 확정: 아래 5개 기업을 최종 선정안으로 정리한다.

[선정 범위]
- 현재 게임에 등록된 미래건설·하늘식품·동방물산·한성공업과 최종보스 기업은 이번 5곳에서 제외한다.
- 원기획서에 있는 미등록 기업 중 플레이어를 공격적으로 견제할 수 있고, 최종보스 기업의 협력사 또는 하위 계열사로 연결해도 기존 컨셉과 어울리는 기업을 선정한다.
- 최종 선정: 폴라리스파이낸스, 대성산업, 신성개발, 블루하버리테일, 오로라푸드테크.
- 아래 최종보스와의 연결 및 견제 방식은 이번에 채택한 스토리 확장 방향이다. 원기획에 해당 지배·협력 관계가 이미 확정되어 있었다는 뜻은 아니다.
- 기존 등록 기업의 존치·모브 전환·NPC 교체를 이 문서 저장만으로 실행하지 않는다. 미래건설 중심의 기존 프롤로그·튜토리얼 계획은 유지한다.

----------------------------------------------------------------
9-1. 폴라리스파이낸스
----------------------------------------------------------------

업종: 금융·투자
중심 인물: 임도현(CEO). 정유라(M&A 본부장)는 협상·인수 경쟁의 주요 인물로 활용한다.
역할: 자금과 지분을 이용하는 직접적인 인수전 상대.

최종보스와의 관계:
최종보스의 자금을 운용하거나 인수 자금을 공급하는 금융 협력사로 설정한다. 높은 수익·담보·지분 조건을 중시하는 기존 성향과 맞는다. 협력이 유리한 동안 최종보스의 확장을 돕는 관계다.

플레이어 견제:
- 플레이어의 인수 대상 지분을 먼저 확보한다.
- 플레이어가 자금이 부족한 시점에 대출·담보·지분 조건을 강화한다.
- 경쟁 매수자에게 자금을 제공해 인수 가격과 협상 부담을 높인다.
- 자금 제공자로 접근한 뒤 거래 조건을 통해 주도권을 확보하려 한다.

스토리 포인트:
도움을 받는 거래가 이후 경영권과 자금 운용의 제약으로 돌아올 수 있다. 이익과 위험을 바꿀 수 있는 거래를 통해 협력 관계를 흔들 여지도 남긴다.

----------------------------------------------------------------
9-2. 대성산업
----------------------------------------------------------------

업종: 중공업·산업설비
중심 인물: 김성호(CEO), 오진우(사업개발총괄).
역할: 규모와 공급망을 활용하는 후반의 대형 인수전 상대.

최종보스와의 관계:
독립적인 경영 조직을 유지하는 제조·설비 핵심 계열사로 설정한다. 최종보스의 자본과 거래망을 활용해 조직 규모와 사업 영역을 키우려는 동기를 둔다.

플레이어 견제:
- 같은 기업을 두고 인수 경쟁을 벌인다.
- 계열사와 주요 협력사의 장기 공급계약을 선점한다.
- 플레이어가 확보하려는 생산시설과 기술 인력에 먼저 접근한다.
- 여러 사업체의 규모를 활용해 플레이어의 확장 비용과 운영 부담을 높인다.

스토리 포인트:
플레이어가 회사를 보유하는 단계를 넘어 여러 인수 기업을 실제로 연결·운영할 수 있는지 시험하는 상대다. 최종보스 직전의 큰 벽으로 활용한다.

----------------------------------------------------------------
9-3. 신성개발
----------------------------------------------------------------

업종: 부동산·복합개발
중심 인물: 정도현(CEO), 강민지(임차인·지역관계 책임자).
역할: 미래건설 등 플레이어 소유 기업을 입지·사업권으로 압박하는 지역 경쟁자.

최종보스와의 관계:
최종보스의 대형 개발사업을 담당하는 개발 계열사 또는 공동사업 파트너로 연결한다. 자본과 도시 영향력이 서로 필요한 관계로 두며, 구체적인 소유 형태는 후속 설계에서 확정한다.

플레이어 견제:
- 미래건설의 핵심 부지·개발권·입찰을 두고 직접 경쟁한다.
- 플레이어가 확장을 준비하면 주변 핵심 입지를 먼저 확보해 선택지를 줄인다.
- 지역사회·임차인·개발 일정이 얽힌 협상에서 플레이어보다 유리한 조건을 확보하려 한다.

스토리 포인트:
자금만으로 해결하기 어려운 사업 갈등을 만든다. 지역 관계와 장기 개발 계획을 확보하면 경쟁 구도를 바꾸거나 협상할 수 있도록 한다.

----------------------------------------------------------------
9-4. 블루하버리테일
----------------------------------------------------------------

업종: 대형 유통·소매
중심 인물: 서유진(CEO), 한도경(데이터총괄).
역할: 플레이어 소유 식품·소비재 기업을 판매망과 소비자 시장에서 압박하는 경쟁자.

최종보스와의 관계:
최종보스 계열 제품의 판매를 담당하는 유통 계열사로 설정한다. 대규모 자본·상품 공급과 전국 판매망을 교환하는 관계다.

플레이어 견제:
- 플레이어가 투자한 기업과 가격·판촉·상품 구성을 두고 경쟁한다.
- 자사 판매망에서 계열 제품에 유리한 진열과 프로모션을 제공한다.
- 입점 조건과 판매 지원 조건에서 플레이어가 더 많은 비용을 부담하게 만든다.

스토리 포인트:
좋은 제품을 보유해도 판매망과 고객 접점을 확보하지 못하면 성장하기 어렵다는 점을 보여준다. 고객 경험·개인정보 보호를 중시하는 기존 성향은 유지하며, 무조건적인 불법 정보 거래나 소비자 기만을 기본 성격으로 덧붙이지 않는다.

----------------------------------------------------------------
9-5. 오로라푸드테크
----------------------------------------------------------------

업종: 대체식품·바이오소재
중심 인물: 김서후(CEO). 정하린(수석과학자)과 한유나(사업개발책임자)는 검증·상용화의 내부 갈등에 활용할 수 있다.
역할: 신제품·특허·출시 속도로 플레이어 소유 식품 기업의 시장을 선점하는 경쟁자.

최종보스와의 관계:
성장 자금과 유통망을 얻기 위해 최종보스의 투자를 받은 전략적 투자 자회사로 설정한다. 빠른 출시·시장 선점·전략적 파트너십을 중시하는 기존 컨셉과 연결한다.

플레이어 견제:
- 하늘식품이 진출하려는 시장에 신제품을 먼저 출시한다.
- 특허·라이선스·선구매계약을 확보해 플레이어의 사업 선택지를 줄인다.
- 최종보스의 자본과 유통 지원을 활용해 연구·출시·시장 확장 속도를 높인다.

스토리 포인트:
플레이어가 단기 수익 확보에 집중하는 사이 다음 시장을 선점하는 상대다. 빠른 성장과 기술 검증 사이의 내부 갈등을 유지해, 구성원 모두가 같은 판단을 하는 기업으로 만들지 않는다.

================================================================
10. 다섯 기업의 역할 분담과 공통 스토리 원칙
================================================================

최종보스의 영향력을 아래 다섯 기반으로 나눈다.
- 폴라리스파이낸스: 자금·지분.
- 대성산업: 생산·설비·공급망.
- 신성개발: 개발권·입지·도시 사업.
- 블루하버리테일: 판매망·소비자 접점.
- 오로라푸드테크: 기술·신제품·신사업 선점.

직접적인 인수전 상대:
폴라리스파이낸스와 대성산업을 중심으로 플레이어의 인수 대상·지분·자금을 놓고 경쟁한다.

소유 기업을 시장에서 압박하는 상대:
신성개발·블루하버리테일·오로라푸드테크는 플레이어가 확보한 기업의 사업 영역을 위협한다. 플레이어의 투자 업종과 성장 방향에 따라 등장 비중을 조절한다.

공통 원칙:
- 다섯 기업이 최종보스의 명령에 무조건 복종하는 구조로만 만들지 않는다.
- 각 기업이 최종보스와 협력해서 얻는 자본·시장·사업 기회·조직적 이익을 분명히 한다.
- 플레이어가 각 기업의 사업과 이익을 위협하면 공개적으로 맞서도록 한다.
- 플레이어가 더 나은 거래를 제시하거나 최종보스가 손실을 떠넘기면 일부 기업을 이탈시키는 협상이 가능하도록 여지를 둔다.
- 회사 내부 인물들은 각자 다른 가치와 이해관계를 가진다. 경쟁 기업의 모든 인물을 동일한 악역으로 취급하지 않는다.
- 플레이어가 다섯 기업과의 갈등을 해결하며 최종보스의 자금·생산·개발·판매·신사업 기반을 단계적으로 약화시킬 수 있게 구성한다.
