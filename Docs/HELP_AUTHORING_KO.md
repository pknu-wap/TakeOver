# 도움말 제작·갱신

- 상단 도움말 버튼은 기존 상단 메뉴 버튼을 런타임 복제한다. 본문·목록·안내창은 이벤트 공용 패널과 버튼을 복제한다. 원본 이벤트 프리팹은 수정하지 않는다.
- 본문 정본: `Assets/Dashboard/Scripts/HelpTopics.cs`. 항목별 조작 순서, 용어 뜻, 판단 시 주의점과 현재 이용 가능 범위를 쉬운 한국어로 작성한다.
- 완전히 새로운 기능을 구현하면 도움말 항목과 확보 가능한 설명용 사진도 함께 갱신한다. 기존 기능 개선에 따른 본문 갱신은 사용자가 요청할 때 진행한다.
- 사진은 `Assets/Resources/HelpImages`의 단일 Sprite다. Topic.image에 확장자 없는 이름을 적는다. 확보하지 못한 사진은 빈 문자열로 두면 자리가 비어 있다. 사진은 클릭해서 크게 볼 수 있다.
- 현재 7개 사진은 직접 캡처한 `QA_ContextUI/Normal`의 실제 게임 화면을 사용한다. 자금·날짜·회사 수치는 예시 화면 값이며 플레이 상황에 따라 달라진다.
- 튜토리얼 안내는 StoryDirector.Finish 공통 종료 경로에서 표시한다. 전체 스킵에도 적용되며, 도움말 안내 확인 여부 때문에 시작 경로가 생략되지 않는다. Game 씬 직접 실행에는 자동 표시하지 않는다.
- `HelpVerification.Run`은 탭/본문/사진 로딩 및 전체 튜토리얼 스킵 뒤 안내창을 검사하고 캡처한다. 정상 진행 종료 안내는 StoryPlayVerification에서도 검사한다.
