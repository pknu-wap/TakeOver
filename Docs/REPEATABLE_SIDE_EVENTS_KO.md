# 반복 서브 이벤트 구성안 — 초반 네 기업·외부 인물 다섯 명

> 2026-11-18 실행 연결 완료. 현재 일정·조건·효과·저장·검증 기준은 [초반 캠페인 구현 현황](EARLY_CAMPAIGN_RUNTIME_KO.md)을 따른다. 아래의 미등록·제안·후속 구현 표기는 원고 작성 당시의 기록이다.

2026-11-17. 사용자 요청에 따른 **대본과 발생 규칙 초안**이다. 신규 사건 등록, 원본 에셋 대사 교체, 확률·반복 판정 코드는 이번 문서 작성에서 적용하지 않는다.

## 구성과 읽는 순서

- [기업 대본 12편](REPEATABLE_SIDE_COMPANY_SCRIPT_KO.md): 회사마다 기존 경영진 면담 1편, 기존 구조조정 면담 1편, 신규 일상 사건 1편.
- [외부 NPC 대본 15편](REPEATABLE_SIDE_NEUTRAL_SCRIPT_KO.md): 윤하진·정수아·김태성·박상현·이민규 각각 3편. 윤하진의 주가조작, 박상현의 정치 후원, 이민규의 인터뷰는 기존 사건을 재작성한다.

총 **27개 대본**이다. 기존 공통 사건의 회사별 변주를 8편, 기존 외부 사건을 3편, 신규 사건을 16편으로 구성한다. 경영진·구조조정은 기존 사건 ID와 회사 문맥을 공유하므로 대본 27편이 서로 다른 이벤트 ID 27개를 뜻하지는 않는다. 아래 안은 기존 공통 정의 5종과 신규 정의 16종에 대응한다.

기존 `inside_info_01`은 미래건설 필수 메인이므로 포함하지 않는다. 그린메일은 응답 완료 및 수락 후 영구 재매수 금지 정책을 가진 특수 일반 사건으로 별도 유지한다. 이를 반복시키거나 수락 뒤 다시 초대하지 않는다. 본 문서의 반복 후보 3편 외에 그린메일 같은 기존 특수 사건이 존재할 수 있다.

이전 기업 대본의 C-H2·C-D2·C-S2 같은 긴 서브 면담 초안은 장면 소재로 보관한다. 이번 3편에 더해 네 번째 반복 사건으로 별도 발행하지 않는다. 필요하면 해당 기업 사건의 긴 응답·변주에 흡수한다. 튜토리얼 소개, 한 번만 오는 첫 연락, 회사 메인 면담은 반복 3편과 별개다.

## 기본 이벤트 등록과 현재 코드의 차이

사용자가 말한 기본 이벤트 데이터베이스는 현재 구조에서 `EventLogic.prefab`의 `EventSystemController.events` 일반 등록 목록에 해당한다. 별도의 일반용 DB SO가 이미 있는 것은 아니다. 이 서브 사건들은 **`EventCategory.General`**로 등록하며 `StoryEventDatabase`에 넣지 않는다. 튜토리얼 전용도 아니다.

현재 코드에서 확인한 점:

1. `onDayStarted`는 적격 정의마다 후보를 발행한다. `Random.Range`는 여러 회사 중 대상을 고르는 데 쓰며 사건 자체의 일별 출현 확률은 아직 없다.
2. `canAppear`는 응답 완료 기록이 있으면 같은 일반 사건·회사 또는 고정 사건을 영구 차단한다. 현재는 미응답 만료 때 7일 대기를 기록한다. 응답 후 반복을 지원하는 설정은 없다.
3. 저장 검증도 완료된 사건과 활성 발생을 동시에 허용하지 않는다. 반복 정책을 추가할 때 생성 로직뿐 아니라 완료/회차·저장 검증도 함께 바꿔야 한다.
4. 공유 정의의 회사별 화자와 원화 선택은 지원하지만 회사별 긴 대사 본문 전체를 교체하는 설정은 아직 없다. 본문·응답 변주 연결이 필요하다. 기존 ID를 임의로 회사별 ID로 바꾸어 과거 참조를 끊지 않는다.
5. 구조조정 사건은 현재 NPC 관계·기억 결과를 전달하지만 실제 인력 감축/재교육·고용 보장까지 일반 사건 선택만으로 완료하는 경로는 확인되지 않는다. 아래 대사는 운영안에 대한 주주의 입장 표명으로 쓴다.

따라서 대본을 일반 목록에 넣는 것만으로 확률 반복이 완성되었다고 설명하지 않는다. 기존 메인·일회성 일반 사건까지 완료 차단을 일괄 해제하지 않는다.

## 발생 규칙 제안

| 항목 | 제안 |
|---|---|
| 일별 판정 | 날짜 갱신 완료 후 대상별로 **20%**를 한 번 판정. 성공 시 조건과 대기기간을 만족하는 3편 중 하나를 동등하게 선택 |
| 확률의 단위 | 기업 4곳·외부 인물 5명별 20%다. 27개 사건이 각각 20%인 것은 아님. 후보가 없는 대상은 발행하지 않음 |
| 새 제안 상한 | 하루 신규 반복 제안 최대 2건. 초과 당첨 대상 중 무작위 선택. 확정 상한 적용 뒤 실제 발행률은 20%보다 낮아질 수 있음 |
| 중복 | 같은 대상의 진행 중 서브 사건은 1건. 동일 사건·회사·회차를 중복 발행하지 않음. 주가조작의 종목 후보와 발신자 윤하진은 별도 개념 |
| 유효기간 | 기존 경영진 2일, 구조조정 3일, 주가조작 2일, 정치 후원·인터뷰 3일 유지. 신규 사건은 기본 2일 제안 |
| 응답 후 대기 | 보통 사건은 완료일 D 기준 **D+3일차부터** 새 판정. 구조조정은 D+7, 주가조작·정치 후원은 D+10 제안 |
| 만료 | 기존 7일 대기를 우선 유지. 단순 거절은 해당 회차 완료이며 연락 영구 단절·배신으로 처리하지 않음 |
| 비용 | 기존 경영진/외부 1 AP, 구조조정 2 AP 유지. 신규 면담은 1 AP 제안. 비용은 실제 카드에 표시 |
| 재평가 | 카드 열기·만남 시작·선택 확정 때 현재 조건을 다시 확인. 잔액 부족 선택은 효과·완료 기록 전에 거부 |
| 로드 | 저장된 당첨·회차·미응답 제안·대기일을 복원. 같은 날짜 새로고침·씬 재진입으로 재추첨하지 않음 |

기업별 3편 모두가 매일 무조건 후보인 것은 아니다. 경영진은 기존 지분 10% 이상, 구조조정은 지분 51% 이상이면서 적자 또는 전기 대비 이익 악화 조건을 유지한다. 신규 기업 일상 사건은 해당 회사 지분 10% 이상 제안이다. 회사가 상장폐지·거래 불가인 경우 발행 정책을 별도 검토한다.

메인 서사의 선택·성공·실패·APEX 단서로 이 사건들을 열거나 닫지 않는다. 사건 본문에도 메인 단서·범인 공개·필수 목표 완료를 넣지 않는다. 기존에 요청한 회사 첫 대면의 메인 연출을 보존하려면 **최초 소개 여부만** 최초 노출에 적용할 수 있다. 이는 구현 전에 확정할 표시 정책이며, 본문은 첫 회/재회 모두 가능한 독립 면담으로 작성했다. 외부 인물은 튜토리얼에서 소개되므로 이후 별도 관계 하한 없이 신규 일상 사건에 접근 가능하다.

필수 미션 강제 진행·실패 전환은 기존처럼 우선한다. 서브 이벤트가 진행 중인 메인 미션을 대체하거나 거래 기한을 자동 연장하지 않는다. 숨긴 제안의 시간을 보존할지 일시 정지할지도 기존 일반 사건과 함께 결정해야 한다.

## 기존 사건을 고치는 범위

- **경영진:** 매번 “처음 보는데 왜 사셨습니까” 대신 그 시점의 투자 의향을 묻는다. 2개 선택과 `investment_review`/`takeover` 의미는 보존한다. 계약·의결권 위임·현재 경영진 영구 보장으로 기록하지 않는다.
- **구조조정:** 대표적 입장 세 가지와 `mass_layoff`/`gradual`/`retain` 식별자를 보존하되, 현재 시스템에서 실행하지 않은 해고·고용 유지 완료를 대사로 주장하지 않는다. 해당 회차 운영안에 대한 의견으로 남긴다.
- **주가조작:** 윤하진의 위험한 제안 성격을 유지한다. “차익 확실”은 제안자의 장담과 실제 결과를 구분하고 선택 설명에서는 수익을 보장하지 않는다. 실제 기존 종목 선택·다음 턴 급등 효과를 없애지 않는다.
- **정치 후원:** 박상현이 후원과 편의를 묶는 위험한 인물이라는 점은 유지한다. 후원 한 번에 법률·공시 의무가 바뀌었다는 표현은 제거한다. 현 구현의 효과는 경영진 면담 발생 기준 완화에 한정되며 메인 10% 미션에는 영향이 없다.
- **인터뷰:** 매번 처음 나타난 회사라고 소개하거나 항상 차입금을 보유한다고 대답시키지 않는다. 현재 공개 가능한 투자 원칙·자금 설명으로 묻고 답한다. 인터뷰 완료와 실제 뉴스 발행은 구분한다.

그린메일 거절 대사도 이후 문구 정리 시 회사별로 자연스럽게 바꿀 수 있으나, 본 27편 대본의 반복 정책으로 전환하지 않는다.

## 회차와 효과의 계약

대본의 ‘이번 검토’, ‘이번 자료’, ‘오늘의 답변’은 새 발생 회차를 뜻한다. 과거 결정을 뒤집거나 영구 약속을 새로 만드는 기본 경로로 쓰지 않는다. 첫 회에는 “잠깐 확인할 게 있습니다”, 재회에는 “이번 건도 말씀을 듣고 싶습니다” 같은 첫 문장만 바꿀 수 있다. 과거 만남을 기억하는 근거는 임시 NPC 기억이 아닌 조우/발생 이력이어야 한다.

신규 사건의 기본 현금·지분 변화는 0이며 관계·관찰 기억 중심이다. 대본의 ‘효과 방향’은 수치 확정 전 설계 메모다. 반복 면담은 작은 변화 위주로 조정하고 기존 ±10 수준의 일회성 보상을 그대로 매번 누적하지 않는다. 동일 NPC 하루 긍정 보상 상한과 과도한 반복의 감쇠는 구현 시 밸런스 대상으로 둔다. 수치를 숨겨 완성됐다고 처리하지 않는다.

주가조작·정치 후원의 기존 현금·경제 효과는 명시한 예외다. 주가조작 효과가 겹친 채 다시 발행되지 않도록 미해결 효과를 검사해야 한다. 정치 후원 기준 완화는 고정된 게임 효과이며 후원마다 10%→20%→30%로 누적하지 않는다. 반복 선택이 과거의 정치 거래 사실을 지우거나 이전 후원금을 환급하지 않는다. 최신 선택과 실제 누적 사실의 저장을 분리해야 한다.

반복 이벤트에는 회차별 고유 발생 ID가 필요하다. 원본 이벤트·회사·선택 인덱스는 유지하고 같은 회차의 관계·기억·현금·경제 효과를 한 번만 적용한다. 스킵·결과 닫기·로드로 재적용하지 않는다. 원본 정의의 NPC 결과 목록을 회차 중에 영구 변경하지 않도록 실행 복제도 점검한다.

## 연출과 검토 상태

기존 기본·암전 스탠딩과 이벤트 UI를 공유한다. 박민우와 이민규의 가벼운 말투는 자기 업무 습관·소소한 불편에 쓰고 해고·피해·안전을 농담거리로 삼지 않는다. 다른 인물의 대사는 기존 프로필을 따른다. 새로운 사진·표정·별도 버튼 양식을 전제하지 않는다.

이 문서의 대본은 기존 에셋·조건·효과와 대조한 제안이다. 원본 `.asset`·프리팹·씬·NPC ID는 수정하지 않는다. 실제 등록 단계에서는 일반 사건 반복 정책·저장 호환·회사별 본문 변주·도움말 갱신과 Play 검증이 필요하다.
